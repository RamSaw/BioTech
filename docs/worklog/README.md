# Worklog

One file per session: `YYYY-MM-DD-short-slug.md`. Written by me, not by AI — AI may format it, but
the predictions and the verdict have to be mine or the whole point is lost.

Two jobs. It is the memory that survives a three-month gap, and it is the raw material for the
interview story.

## Template

```markdown
# YYYY-MM-DD — <topic>

**Phase:** <from docs/TRACK.md>
**Time:** <hours>

## Question
What am I trying to find out today? One sentence. If I cannot write it, I am not ready to start.

## Prediction
What I expect to see, and why. A number or a shape, written BEFORE running anything.

## What happened
The actual result. Numbers, not impressions.

## Surprise
Where prediction and outcome diverged. If this is empty, I was not predicting or not pushing.
This field is the one that makes the entry worth writing.

## Concepts I had to learn
Named, with a one-line explanation in my own words. These become the weekly retrieval quiz.

## Verdict
Do I believe the result? What would make me not believe it?

## Next
The single next action.
```
