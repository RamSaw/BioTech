# Workbook

Concept notes, one file per concept cluster (sessions go in `../worklog/`, not here).

## The split

- **Handwritten notebook = primary.** Derivations, diagrams, false starts. Wrong answers get crossed
  out, never erased — the crossed-out version is what memory hooks onto.
- **This directory = the survivor.** Written *after* the handwritten pass, in my own words,
  compressed. Not a transcription: the compression is itself the retrieval, which is why copying
  notes verbatim would defeat the point.
- **Exception:** `vocabulary.md` is electronic-first. Lookup, not understanding — see that file.

## Entry template

```markdown
# <concept>

**Met while:** <which TRACK.md step raised it>

## In my own words
The explanation, without looking at notes or asking AI. If I cannot write this, I have not
learned it yet and should say so rather than paste something.

## Why it is true
The mechanism, not the statement.

## What I got wrong first
The version I believed before. Keep this — it is the most useful part of the entry.

## How it bites in practice
Where this changes a decision in the project.
```
