# CLAUDE.md

Read these before working in this repo:

- **[`docs/teaching-protocol.md`](docs/teaching-protocol.md)** — how to teach in this project. This
  repo's purpose is learning, not shipping code. Read it before answering any conceptual question or
  starting a learning session; it defines what every session must contain and what must not be done
  for the user.
- **[`docs/TRACK.md`](docs/TRACK.md)** — current phase, next step, and the gates between phases.
  Check which step is active before proposing work.
- **[`development_guide.md`](development_guide.md)** — coding, notebook, linting and dependency
  rules, plus the `[begin]` / `[finish]` protocols.
- **[`docs/decisions/`](docs/decisions/)** — settled decisions on where code, docs, datasets and
  weights live. Do not re-litigate these without reason.

Current state is recorded in [`docs/worklog/`](docs/worklog/) — read the most recent entry at the
start of a session rather than inferring project state from the code.
