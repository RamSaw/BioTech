# BioTech

Pet BioTech projects, and the learning track behind them.

## Start here

- [`docs/TRACK.md`](docs/TRACK.md) — the plan: current phase, next step, and the gates between
  phases. The single source of truth for what is being worked on.
- [`docs/worklog/`](docs/worklog/) — one entry per working session. The most recent entry is the
  current state of the project.
- [`docs/workbook/`](docs/workbook/) — concept notes and vocabulary, plus a quiz bank for
  closed-book retrieval.
- [`docs/teaching-protocol.md`](docs/teaching-protocol.md) — how AI assistance is expected to work
  here. This repository exists to produce understanding, not just working code.
- [`docs/decisions/`](docs/decisions/) — settled decisions, e.g. where datasets and model weights
  live.
- [`docs/reading-routine.md`](docs/reading-routine.md) — how the textbook background track is read.
- [`docs/environment-setup.md`](docs/environment-setup.md) — cloud environment configuration.
- [`development_guide.md`](development_guide.md) — coding, notebook and dependency conventions.
